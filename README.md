# Code World 🧑‍💻💬

Code World is a real-time collaborative code editor that allows multiple users to edit code together, chat, and collaborate seamlessly. It supports live code execution, syntax highlighting, file/folder management, drawing, and AI code suggestions — all in one place.

> 🚀 Built with React, TypeScript, Node.js, Express, Socket.IO, and Tailwind CSS.

---

## 🌟 Features

- ✅ **Real-Time Collaboration** – Sync code live across multiple users
- 💬 **Live Chat** – In-room chat for instant communication
- 📁 **Multi-file & Folder Support** – Create and organize code files
- ▶️ **Code Execution** – Run code and view output (via Piston API)
- ✍️ **Collaborative Drawing** – Built-in canvas for diagrams & planning
- 🔐 **Room-based Sessions** – Join using unique room IDs
- ⚡ **Fast & Responsive UI** – Built with Vite + Tailwind

## 🛠️ Tech Stack

**Frontend**
- React + TypeScript
- Vite
- Tailwind CSS
- Socket.IO-client
- Zustand (for state management)

**Backend**
- Node.js + Express
- Socket.IO-server
- Piston API (for code execution)
